# Office and Excel Assistant Skill

## Use When
- User needs Excel formulas, report update, table cleanup, formatting.
- User asks Word/PPT operation help.

## Workflow
1. Detect available suite: Excel/LibreOffice/WPS.
2. Locate target file and sheet structure.
3. Suggest formula or automation steps.
4. For repetitive operations, propose macro/script workflow.

## Coverage
- Pivot table, VLOOKUP/XLOOKUP, conditional formatting.
- CSV import cleanup and encoding handling.
- Finance/report template update.
