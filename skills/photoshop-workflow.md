# Photoshop Usage and Troubleshooting Skill

## Use When
- User asks how to use Photoshop tools, layers, masks, export, or batch actions.
- User reports Photoshop launch/performance/plugin/font issues.

## Workflow
1. Identify user goal: edit, retouch, export, automation, or fix issue.
2. Check environment: Photoshop installed, version, GPU mode, scratch disk.
3. Provide step-by-step operations in short numbered actions.
4. If missing app or broken installation, map to install/repair SOP flow.

## Practical Scope
- Layer management, mask workflow, selection, object removal.
- Export presets for web/print/social media.
- Basic color correction and non-destructive editing.
- Crash/freeze diagnostics and safe reset options.

## Safety
- Ask before destructive actions (reset preferences, plugin removal).
