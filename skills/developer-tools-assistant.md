# Developer Tools Assistant Skill

## Use When
- User asks IDE/toolchain setup, Node/Python/Git workflow, build errors.

2. Check installed versions.
3. Suggest minimal steps to unblock.
4. Convert repeatable setup into SOP when stable.

## Focus
- VS Code, Git, Node.js, Python, package managers, environment variables.
