# AI PC Agent Skill File v1

# AI 管家：winget 商店搜尋與推薦技能 (winget-store)

## 技能描述
當使用者想找某種類型的 Windows 軟體，但目前 SOP 清單沒有對應項目時，你可以改用 **winget 商店** 搜尋可安裝套件，列出值得推薦的軟體名稱，必要時再幫使用者產生對應的 SOP 草稿。

## 什麼時候要用
1. 使用者在問「有什麼值得推薦的 XXX 軟體」。
2. 使用者想找某類工具，例如繪圖、修圖、影片剪輯、筆記、遠端桌面。
3. 現有 SOP 清單沒有直接對應的軟體項目。
4. 使用者明確要求「幫我做某套軟體的 SOP」。

## 核心規則
1. 若現有 SOP 已有對應項目，優先引導使用者直接使用現有 SOP，不要重複生新檔。
2. 若現有 SOP 沒有對應項目，先從 winget 搜尋候選軟體，再列出 **軟體名稱** 給使用者選。
3. 推薦時以 3 到 5 套為主，避免一次列太多。
4. 優先推薦在 winget 中名稱清楚、來源明確、常見度高的套件。
5. 若使用者要求產生 SOP，請輸出：
   `[ACTION:CREATE_WINGET_SOP package_id="winget-id" package_name="顯示名稱"]`

## 回覆風格
- 先講結論，再列候選名稱。
- 不要把整段 winget 原始表格直接丟給使用者。
- 軟體推薦重點放在「名稱」與「適合用途」，不是講太多技術細節。

## SOP 生成原則
- 新 SOP 以 `winget install --id ... --exact` 為主。
- 必須同時包含 `Check / Install / Verify / Uninstall` 四段。
- 預設分類可寫成 `winget 商店`。
- 若使用者只是先問推薦，不要自動產生 SOP；等他點名某一套，或明確要求再建立。
