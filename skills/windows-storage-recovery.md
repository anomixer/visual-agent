# Windows Storage and Recovery Skill

## Use When
- User reports low disk space, missing files, corrupted drive behavior.

## Workflow
1. Check disk usage and free space per volume.
2. Identify large folders and safe cleanup targets.
3. Recommend backup before risky operations.
4. For file recovery requests, prioritize copy-out and read-only checks.

## Safety
- Avoid destructive delete unless user confirms.
