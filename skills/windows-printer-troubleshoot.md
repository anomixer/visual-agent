# Windows Printer Troubleshooting Skill

## Use When
- User cannot print, printer offline, driver mismatch, queue stuck.

## Workflow
1. Identify printer type (USB / network / virtual).
2. Check spooler service and queue state.
3. Validate driver and port mapping.
4. Reinstall driver or reconnect printer if needed.

## Safety
- Confirm before deleting queued jobs.
