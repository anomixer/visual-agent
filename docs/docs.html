第一次進入,先看這幾個地方

幾分鐘就能跑起來。設定好 Provider,就能在右側對話區直接下指令。

介面導覽

五個你會常用的地方

1

右下角 · 語言切換

介面支援中英切換。

2

右上角 · AI 供應商與模型

設定 Provider、Base URL、API Key / OAuth 2.0 與模型名稱。

3

中央 · Chalkboard

塗鴉、貼照片,讓 AI 辨識內容;遠端連線時可即時共享快照。

4

左側 · 推薦清單 / SOP 清單

按 + 加入任務清單,按 Play 可直接執行。

5

右上角 · 遠端 AI

輸入對方 IP 即可雙機連線,tag 自己或對方的 AI 請它幫忙。

AI 對話與 Provider

接上你喜歡的模型

🦙

本機 Ollama

系統會自動偵測 Ollama;若缺少可透過內建 SOP 安裝,並下載預設模型 gemma4:e2b-it-qat。UI 顯示「AI 就緒」即可對話。

☁️

其他 Provider

OpenAI、Groq、DeepSeek、Mistral、Together AI、Gemini 走 OpenAI-compatible 流程;Anthropic Claude 用原生 /v1/messages;Custom 支援 API Key 與 OAuth 2.0。
