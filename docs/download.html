選一種方式,把它裝起來

Windows 10 / 11 使用者建議走 Releases 安裝版,最省事;開發者可直接從原始碼跑。

⬇ 前往 Releases 閱讀文件
方式一

Windows 安裝版(推薦)

適合只想快速體驗的你。

1

下載 setup.exe

到 GitHub Releases 下載最新的 Windows setup.exe。

2

執行安裝檔

直接執行安裝檔完成 setup(會觸發 UAC 提權)。

3

雙擊啟動

雙擊 Visual Agent 執行檔即可。

4

自動初始化

首次啟動會自動完成環境檢查與初始化。

方式二

從原始碼執行

Windows PowerShell
# 1. 複製專案
$ git clone https://github.com/anomixer/visual-agent.git
$ cd visual-agent
# 2. 安裝相依套件
$ npm install
# 若 PowerShell 擋下 script execution:
$ powershell -ExecutionPolicy Bypass -Command "npm install"
# 3. 啟動開發伺服器
$ npm start
# 4. 開啟 http://localhost:3210
環境需求

開始前請確認

OS Windows 10 / 11 Node.js 18 以上 Ollama 選用(本地 LLM 對話) 權限 部分 SOP 需管理員權限(UAC)

若只使用推薦清單與待辦管理,不一定需要先安裝 Ollama。
