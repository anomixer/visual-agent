功能一覽

為你的電腦,造一個會進化的管家

從對話、塗鴉到系統自動化,Visual Agent 把 AI 能力收進一個純圖形介面的控制中心。

🎨

互動式 Chalkboard 共享

中央 Chalkboard 支援粉筆塗寫、局部板擦、圖形、圖片放置、文字框與 PNG 匯出。遠端連線時可即時共享快照,隨手標記讓 AI 看懂。

🌐

Double Agent 模式

支援兩台實體電腦透過專用協議連線,本地 AI 先答、遠端 AI 隨後補充,也能請朋友和 AI 一起幫你修電腦。

📊

圓圈式硬體環形監控

即時探測 CPU、GPU、RAM、Disk,並能透過專屬插件精準監控 NVIDIA 顯示卡的溫度、VRAM 與即時負載。

🔍

Browser Use 聯網即時查詢

當本地知識不足時,AI 自動呼叫 Browser Use 搜尋、抽取來源頁面文字並整理答案,支援天氣、新聞與最新股價。

⚡

雙向自動化軟體管理

整合 winget、Microsoft Store、GitHub Releases,為 Chrome、Steam、Office 等常用工具打造防錯的「安裝與移除」雙向 SOP 執行鏈。

🛡️

Consent-before-action 安全防護

AI 執行任何系統變更前,先將其加入待辦任務清單,等待你手動點擊確認後才執行,防止無人值守的自動修改與潛在風險。

🧠

經驗學習與自我進化

每次任務執行的成敗皆會沉澱至本地經驗庫(Exp),AI 自動讀取並進行敏感資訊遮罩,下次類似任務主動避坑。

⚗️

19 個 Hermes Agent 領域知識庫

融合 NousResearch 專業級 Hermes Agent 的 19 大領域 Skills,涵蓋 Data Science、DevOps、Red Teaming 等,對話時動態注入,回答更專業。

📦

Tauri 打包 / 插件系統

可打包成獨立 Windows EXE,Node 後端以 sidecar 隨附;並能用 .js 擴充系統監控能力,彈性極高。
